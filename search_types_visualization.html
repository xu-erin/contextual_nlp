🔍 Search Types Explained

Keyword Search

📝 Query: "unblinding clinical trial"
How it works: Looks for documents containing the exact words from your query.
Doc 1: "Clinical trial unblinding occurred"
✓ Contains both "unblinding" AND "clinical trial"
Doc 2: "Patient discovered treatment assignment"
✗ No exact match for query terms
Doc 3: "Unblinding study protocol"
✓ Contains "unblinding"
✓ Strengths:
  • Fast and simple
  • Predictable
  • Good for exact matches

Semantic Search

🧠 Query: "unblinding clinical trial"
How it works: Converts text to numerical vectors (embeddings) and finds documents with similar meaning using cosine similarity.
Doc 1: "Clinical trial unblinding occurred" (0.95)
Perfect semantic match - nearly identical meaning
Doc 2: "Patient discovered treatment allocation" (0.88)
Strong match - captures synonym "allocation" for "assignment"
Doc 3: "Inadvertent exposure of treatment arm" (0.82)
Good match - understands related concepts
✓ Strengths:
  • Understands meaning & context
  • Finds synonyms & related concepts
  • More relevant results

Hybrid Search

⚡ Query: "unblinding clinical trial"
How it works: Runs BOTH keyword search AND semantic search in parallel, then combines and ranks the results intelligently.
Keyword + Semantic Combined
🔹 Gets exact matches from keyword search (high precision)
🔹 Adds semantic understanding from embeddings (high recall)
🔹 Reranks by relevance using both signals
✓ Strengths:
  • Best of both worlds
  • Highest precision & recall
  • Handles both exact and semantic matches
  • Most relevant results first
